# Maintainers

This repository is maintained by the SeeItFlow organization. Responsibility for the catalogue, issue triage and review rests with the organization rather than with named individuals.

Maintainer names, public profiles and contact details are not listed. They will be added only after the owner approves each public attribution.

## Responsibilities

- Verify every catalogue link against its live destination before it is added or changed.
- Keep entry descriptions original, specific and consistent with the linked lesson.
- Review issues and pull requests against [CONTRIBUTING.md](CONTRIBUTING.md).
- Enforce the [Code of Conduct](CODE_OF_CONDUCT.md).
- Handle security reports as described in [SECURITY.md](SECURITY.md).
