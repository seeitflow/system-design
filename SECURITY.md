# Security policy

## Scope

This policy covers the contents of this repository: its documentation, catalogue data, scripts and GitHub Actions workflows.

Report the following privately, not in a public issue:

- Credentials, tokens or personal data committed by accident.
- A catalogue link that points to a malicious or compromised destination.
- A vulnerability in the validation scripts or workflows.

Never post credentials or exploit details in a public issue, pull request or discussion.

## How to report

Use GitHub private vulnerability reporting from the **Security** tab of this repository. Do not use public issues for these reports.

## Out of scope

Vulnerabilities in the SeeItFlow website or application are not handled in this repository. Report them through the security contact published on the official SeeItFlow website.
